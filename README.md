# 👋 Hi, we're Cray Group LTD

## 🧠 Kenyan Software Company | 🔧 ISP Automation Experts | 🌍 Powering Networks Across Africa

Welcome to our GitHub! At **Cray Group LTD**, we specialize in building robust, modern software solutions for Internet Service Providers (ISPs), including Hotspot Systems, Billing Platforms, and Monitoring Tools.

---

## 🚀 What We Build
- 🎫 **Hotspot Management System** – MikroTik-based, with STK Push payments, bandwidth tracking, voucher control.
- 💳 **ISP Billing Platform** – FreeRADIUS integration, auto invoicing, master/sub-account management.
- 📡 **MikroTik Monitoring Tool** – Interface and router monitoring using FastAPI, SNMP, Ping, Alerts (Telegram, SMS).
- ⚙️ **Network Automation Tools** – Scheduled router backups, link monitoring, auto-responses.
